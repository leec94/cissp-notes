# Chapter 5: Protecting Security of Assets
## Notes
- government classifications 
  - Top Secret
  - Secret
  - Confidential
  - Unclassified
- private sector classifications
  - critical / proprietary
  - private
  - sensitive
  - public
- data owner: the person(s) (or entity) assigned specific responsibility for a data asset in order to ensure its protection for use by the organization. holds legal rights and defines policies
- data controller: the entity that makes decisions about the data they are collecting. the "why" and "how" of personal data collection and use
- data processor: the entity that performs operations on data on behalf of a data controller. ex: cloud provider
- data custodian: a subject who has been assigned or delegated the day-to-day responsibility for proper storage and transport as well as protecting data, assets, and other organizational objects. technical responsibility
- data steward: business responsibility for data, such as metadata definition, data quality, governance, compliance, etc. 
- data subject: individual to whom person data pertains
