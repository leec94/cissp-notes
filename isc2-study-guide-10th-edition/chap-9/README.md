# Chapter 9: Security Vulnerabilities, Threats, and Countermeasures
## Notes
- protection rings: conceptual layering that segregates and protects operational domains from each other
- ring 0: most trusted, firmware, OS kernel, memory and other critical system related processes
- ring 1: os components
- ring 2: libraries, drivers
- ring 3: user programs and applications, least trusted, user mode 
- distributed computing environment (DCE): collection of individual systems that work together to support a resource or provide a service. implemented as client-server architectures, three-tier architectures, multi-tier architectures, and as peer-to-peer architectures
  - ex: for scientific and medical research projects, education projects, and industrial apps
- interface definition language (IDL): language used to define the interface between client and server processes in a distributed system
  - ex: RPC, COBRA, DCOM
